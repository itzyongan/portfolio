# Yong An Hong — Cybersecurity Portfolio

🌐 **Live website:** [https://itzyongan.github.io/portfolio/](https://itzyongan.github.io/portfolio/)

A personal portfolio for **Yong An Hong**, a first-year Cybersecurity student at the American University of Phnom Penh. The site introduces my background, showcases projects, highlights certificates, and provides ways to connect.

## Website Sections

- **About** — a short introduction and background.
- **Projects** — selected work, including:
  - [Asia PvP Servers](https://asia-pvp-servers.vercel.app/) — a directory of Asia-based Minecraft PvP servers.
  - **Password Strength Checker** — a project focused on evaluating password strength.
- **Certificates** — certificates and learning achievements.
- **Find me** — links to connect online.

## Run Locally

This repository currently contains the deployed website as `index.html`.

1. Clone the repository:

   ```bash
   git clone https://github.com/itzyongan/portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd portfolio
   ```

3. Open `index.html` in your browser.

No build step is required to view the committed HTML file.
